# AutoSync Resolve Studio — OTA Update Server

Sıfır bağımlılıklı (pure Node.js), yüksek performanslı güncelleme dağıtım sunucusu ve Web Yönetim Paneli.

## Özellikler
- 🔄 **OTA Güncelleme API:** `/version.json` (Kurulu uygulamalar için otomatik sürüm kontrolü)
- 🎛️ **Yönetim Paneli:** `/admin` (Web arayüzü ile yeni sürüm ve changelog yayınlama)
- 📊 **İstatistik Takibi:** `/api/stats` (Kaç bilgisayar kontrol etti, kaç indirme yapıldı)
- ☁️ **%100 Ücretsiz:** Render.com, Railway veya kendi sunucunuzda sıfır maliyetle çalışır.
