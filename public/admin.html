🌐 Ücretsiz İnternet Yayını (Render.com / GitHub)
Bu güncelleme sunucusunu internet üzerinden tamamen ücretsiz ($0/ay) canlıya almak için 2 kolay seçenek:

1. Seçenek (Render.com - 100% Ücretsiz Node.js Cloud Sunucusu):
• render.com'a ücretsiz kaydolun.
• "New Web Service" butonuna basın ve bu klasörü (veya GitHub reponuzu) bağlayın.
• Render size https://autosync-update.onrender.com gibi ücretsiz bir HTTPS adresi verir.
• Uygulamanın update_config.json dosyasına bu adresi eklemeniz yeterlidir.

2. Seçenek (GitHub Releases - Sınırsız Hızlı CDN):
• GitHub'da ücretsiz bir depo açıp version.json dosyasını yükleyin.
• İndirme bağlantısı olarak GitHub Releases linkini ekleyin.
